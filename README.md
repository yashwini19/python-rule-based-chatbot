# Basic Rule-Based Chatbot

A simple and interactive chatbot built using Python. This project was created to practice Python fundamentals such as conditional statements, loops, functions, and working with built-in modules. The chatbot responds to predefined user commands, making it a beginner-friendly example of a rule-based conversational program.

---

## About the Project

This chatbot is designed to simulate a basic conversation by recognizing specific user inputs and providing appropriate responses. It demonstrates how simple programming logic can be used to create an interactive command-line application without relying on Artificial Intelligence or Machine Learning.

The project focuses on writing clean, readable, and well-structured Python code while making the chatbot engaging through personalized greetings, random responses, jokes, and motivational quotes.

---

##  Features

-  Greets the user by name
-  Displays a greeting based on the current time of day
-  Responds to predefined user commands
-  Shows the current date
-  Displays the current time
-  Tells random programming jokes
-  Shares motivational quotes
-  Responds politely to thank-you messages
-  Includes a help menu with available commands
-  Handles unknown inputs gracefully
-  Allows users to end the conversation using the `bye` command

##  Available Commands

| Command | Description |
|---------|-------------|
| hello / hi | Greets the user |
| how are you | Displays a friendly response |
| time | Shows the current time |
| date | Displays today's date |
| joke | Tells a random programming joke |
| quote | Displays a motivational quote |
| thank you | Responds politely |
| who made you | Displays chatbot information |
| help | Shows all available commands |
| bye | Ends the conversation |
